### Added
• **Reasoning effort** (Server Settings → Reasoning): Default / Low / Medium / High. Passed to the model as `--reasoning-effort`; it works on models trained with effort levels (e.g. gpt-oss). Other models ignore it — use Thinking limit for those.
• **Thinking limit** (Server Settings → Thinking limit): Unlimited / Off / 512 – 8192 tokens. Caps how long a thinking model (Qwen3, DeepSeek-R1, …) may reason before it must answer (`--reasoning-budget`), with a short hand-off message so the answer isn't cut off mid-thought.
• Both options are only passed when the installed llama.cpp supports them. Token limits need a recent llama.cpp build — use **Check for llama.cpp Update** if the setting has no effect.

### Fixed
• **RAM estimate line** in Server Settings no longer gets cut off; the context warning now shows on its own line with the model's trained limit.
