### Fixed
• **Start Server works again after upgrading with Homebrew.** `brew upgrade` removes the server's LaunchAgent as part of uninstalling the previous version, so after an upgrade the **Start Server** menu item silently did nothing. LlamaMate now recreates the LaunchAgent automatically — when the app launches and before starting the server. The server is not started automatically; it starts when you choose **Start Server** (or at the next login, as before).
• **Clear errors instead of silence.** If the server cannot be started (llama.cpp not installed, or `launchctl` refuses), an alert now explains why.
• **Apply & Restart while stopped** now starts the server instead of doing nothing.

**Upgrade:** `brew update && brew upgrade --cask llamamate`
