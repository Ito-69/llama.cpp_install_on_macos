### Security & Privacy
• **Local-only by default**: New installs bind the server to `127.0.0.1` (this Mac only). An existing `0.0.0.0` setup is kept as-is. A new **Allow access from local network** checkbox in Server Settings controls LAN access.
• **Optional API key**: Generate a key in Server Settings to require it for API requests. It is passed via `--api-key-file`, so it never appears in the process list. `/health` stays open for status checks.
• **Hugging Face token in Keychain**: The token moved from preferences (plain text) to the macOS Keychain. Existing tokens are migrated automatically.
• **Hardened config**: `server.conf` is now owner-only (`0600`), every value is quoted and escaped, and numeric settings are validated in the app, the installer and the start script.

### Fixed
• **Flash Attention / KV cache crash**: Turning Flash Attention off with a quantized KV cache (`q8_0`/`q4_0`) no longer stops the server from starting — the cache falls back to `f16` automatically (in Settings and in the start script).
• **`brew uninstall` now stops the server**: The LaunchAgent is unloaded and removed. `brew uninstall --zap` also removes config, logs and preferences.
• **Safer in-app Uninstall**: Removes only `.gguf` model files (never the whole `~/models` folder) and no longer deletes a Homebrew-managed app bundle.
• **Accurate server status**: Status now comes from `/health` with three states — running, loading model, stopped — and detects when another app is using the port.
• **Update check**: Version comparison handles pre-release suffixes correctly.

### Model Downloads
• **Resumable downloads**: Cancelled or interrupted downloads continue where they stopped, even after quitting the app.
• **Integrity & space checks**: File size is verified before a model is saved, and free disk space is checked before a download starts.
• **Split & nested GGUF**: Multi-part models (`-00001-of-0000N`) download as one item, and files inside repo subfolders now work.
• **Faster file lists**: One Hugging Face API call instead of one request per file; more quantization types recognized (IQ*, `*_K_L`, MXFP4, BF16).

### Performance
• **Cache reuse** (`--cache-reuse 256`): Faster multi-turn chat and regenerate. **On by default.**
• **Optional**: Keep model in RAM (mlock) and Batch threads (`-tb`).
• **Version-aware flags**: New flags are passed only if the installed llama.cpp build supports them.
• **Better RAM estimate**: KV cache size is calculated from the model's GGUF metadata and compared with the Metal GPU working-set limit; warns when the context exceeds the model's trained length.
• **Lighter app**: The menu is no longer rebuilt every 5 seconds, status checks run off the main thread, the log viewer reads only the end of the log, and server logs rotate above 20 MB.

### Upgrade Notes
• The server start script is refreshed automatically when the app launches; the new settings apply on the next server start.
• Cache reuse is enabled after upgrading — you can turn it off in Server Settings.
• If you reach the server from other devices, your existing network setting is preserved; consider adding an API key.

**Upgrade:** `brew update && brew upgrade --cask llamamate`
