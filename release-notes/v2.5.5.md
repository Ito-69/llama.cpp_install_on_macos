### Fixed
• **Community models didn't appear** after upgrading from 2.5.3: a model list cached by the older version was used instead of the newer one built into the app. LlamaMate now uses whichever list is newer, and fetches the latest list right away when you turn on **Show community models**.
• Tooltips in the Browse table are shown only for columns that can be cut off, so a tooltip from a neighbouring cell no longer pops up in the wrong place.

**Upgrade:** `brew update && brew upgrade --cask llamamate`
