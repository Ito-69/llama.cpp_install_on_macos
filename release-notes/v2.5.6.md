### Changed
• **One request slot by default.** The server now runs with 1 parallel slot (`-np 1`) unless you choose otherwise. For one person using one app this is faster, especially with MTP, and uses less memory. Extra requests wait their turn instead of running at the same time.
• If several apps or people use your server at once (Open WebUI, for example, generates chat titles in parallel), choose **2**, **4** or **Auto** in **Settings → Parallel**. Values you've already chosen are kept; only the old "Auto" default changes to 1.

**Upgrade:** `brew update && brew upgrade --cask llamamate`
