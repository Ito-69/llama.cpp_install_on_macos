### Hugging Face token — only when you need it
• **No token question during install.** Public models, including the default one, download without an account, so the first-run prompt is gone.
• **Asked at the right moment.** When Hugging Face limits downloads, or a model needs a login or licence approval, LlamaMate explains what happened and offers **Add Token…** or **Open Model Page**. If your saved token is rejected, it says so and offers **Change Token…**.
• **One place to manage it**: **Hugging Face: Set Token…** at the top right of the Models window shows whether you're signed in (and as whom). Paste a token, **Test** it, **Save** or **Remove** it. Stored in the macOS Keychain, as before.
• **Uses your Hugging Face CLI login automatically.** If you've run `hf auth login`, LlamaMate picks up that token (`~/.cache/huggingface/token`, `HF_HOME`, `HF_TOKEN_PATH`) unless you save a different one.
