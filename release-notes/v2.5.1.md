### Improved
• **Server Settings now uses tabs** — **Model**, **Performance**, **Network** and **Advanced**. The window is about a third shorter (600 instead of 930 points), so it fits on 13" MacBook screens; it used to run off the bottom there, hiding Apply & Restart.
• The **Profile** preset stays above the tabs, and the RAM estimate, system info and Apply & Restart stay below them, so they're visible from every tab.
• If LAN access is on without an API key, the tab reads **Network ⚠︎**, so the warning isn't hidden on another tab.
• The last tab you used is remembered.

**Upgrade:** `brew update && brew upgrade --cask llamamate`
